1. صورة رقم الشاسيه للعربية جديد

كل عربية بقى ممكن يكون ليها صورة واحدة اختيارية لرقم الشاسيه. مفيش endpoint جديد: الصورة بتترفع من APIs الإضافة والتعديل الموجودة.

حقل الرفعvin_image في multipart/form-data
حقل القراءةvin_image_url: رابط كامل أو null
الأنواع والحجمjpg, jpeg, png, webp، بحد أقصى 12 ميجا، والسيرفر بيصغّرها لوحده لـ 2000 بكسل ويحفظها JPEG
الصلاحيةowner و cashier و technician_cashier (صلاحية customers.manage). الفني ممنوع.

إضافة عربية بصورة

POST/api/v1/center/vehicles

نفس طلب الإضافة الحالي. لو فيه صورة يتبعت multipart/form-data، ومن غير صورة يفضل JSON عادي.

const form = new FormData();
form.append('customer_id', '1');
form.append('plate_number', 'ب ج 456');
form.append('vin', 'JTDBR32E720123456'); // optional
form.append('vin_image', file);          // File from <input type="file">

await fetch(`${API}/center/vehicles`, {
  method: 'POST',
  headers: { Authorization: `Bearer ${token}`, Accept: 'application/json', lang: 'ar' },
  body: form, // don't set Content-Type yourself; the browser adds the boundary
});

رفع أو تغيير الصورة لعربية موجودة

POST/api/v1/center/vehicles/{id} ومعاه _method=PUT

مهم: الطلب لازم يتبعت POST ومعاه حقل _method قيمته PUT. لو اتبعت PUT مباشرة ومعاه ملف، PHP مش هيقرا الملف والصورة مش هتتحفظ.
const form = new FormData();
form.append('_method', 'PUT');
form.append('vin_image', file);
form.append('color', 'أسود'); // any other update field can go along

await fetch(`${API}/center/vehicles/${id}`, {
  method: 'POST',
  headers: { Authorization: `Bearer ${token}`, Accept: 'application/json' },
  body: form,
});

الصورة القديمة بتتمسح من السيرفر أوتوماتيك.

مسح الصورة

PUT/api/v1/center/vehicles/{id}

{ "vin_image": null }
أي PUT مافيهوش vin_image خالص مابيلمسش الصورة. يعني شاشة التعديل الحالية مش محتاجة تتغير.

العرض

vin_image_url بيرجع في كل رد فيه عربية: الإضافة، والتعديل، و GET vehicles/{id}، وقايمة العربيات.

{
  "id": 12,
  "plate_number": "ب ج 456",
  "vin": "JTDBR32E720123456",
  "vin_image_url": "https://.../storage/maintenance-centers/1/vehicles/AbC123.jpg"
}

الأخطاء

الكودالسبب
422الملف مش صورة، أو نوعه مش مسموح، أو أكبر من 12 ميجا
404العربية مش موجودة، أو تبع مركز تاني
403المستخدم مالوش صلاحية (زي الفني)
413الملف أكبر من حد السيرفر نفسه، وساعتها الرد ممكن مايكونش JSON

توصيات

  • الضغط بيحصل على السيرفر: الصورة بتتصغّر لـ 2000 بكسل على الضلع الطويل وبتتحفظ JPEG (غالباً أقل من ميجا). ضغطها في الفرونت قبل الرفع اختياري، بس بيسرّع الرفع على النت الضعيف.
  • اتحقق من الحجم والنوع في الفرونت قبل الإرسال.
  • على الموبايل استخدم accept="image/*" capture="environment" عشان الكاميرا الخلفية تفتح على طول.
  • في صفحة العربية: اعرض الصورة، ومعاها زرار "تغيير" وزرار "مسح".
  • ابعت Accept: application/json دايماً.

مش مدعوم: رفع الصورة من شاشة الفاتورة أو من "إضافة عميل بعربياته"، والصورة بتترفع بعدها من صفحة العربية. صورة واحدة بس لكل عربية.

2. إعدادات التذكيرات جديد

3 حقول جديدة في نفس endpoints الإعدادات الموجودة:

GET/api/v1/center/settings
PUT/api/v1/center/settings (صلاحية settings.manage، يعني صاحب المركز)

الحقلالنوعالافتراضيالوصف
whatsapp_service_reminder_enabledbooleanfalseتذكير العميل بمعاد الصيانة قبلها بيوم
whatsapp_debt_reminder_enabledbooleanfalseتذكير العميل بالمديونية اللي عليه
debt_reminder_daysinteger، من 1 لـ 36530كل كام يوم يتفكّر العميل بمديونيته

مثال تعديل

PUT /api/v1/center/settings
{
  "whatsapp_service_reminder_enabled": true,
  "whatsapp_debt_reminder_enabled": true,
  "debt_reminder_days": 15
}

شكل الرد (الحقول الخاصة بالواتساب)

{
  "whatsapp_connected": true,
  "whatsapp_invoice_enabled": true,
  "whatsapp_payment_enabled": true,
  "whatsapp_service_reminder_enabled": true,   // new
  "whatsapp_debt_reminder_enabled": true,      // new
  "debt_reminder_days": 15                     // new
}
اقتراح للـ UI:
  • حط الحقول التلاتة في قسم الواتساب جنب "إرسال الفاتورة" و"إرسال الإيصال".
  • اقفل حقل debt_reminder_days (disabled) لو تذكير المديونية مقفول.
  • لو whatsapp_connected = false، اعرض تنبيه إن التذكيرات مش هتتبعت لحد ما الواتساب يتربط.

الأخطاء: 422 لو debt_reminder_days مش رقم صحيح أو برّه 1–365، و 403 لغير صاحب المركز.

3. التذكيرات بتشتغل إزاي

السيرفر هو اللي بيبعتها لوحده كل يوم الساعة 10 الصبح بتوقيت القاهرة، والفرونت مش محتاج يعمل أي حاجة غير الإعدادات. الشرح ده عشان تكتب نص مساعد (hint) صح جنب الحقول.

تذكير الصيانة

  • بيتبعت قبل next_service_date اللي في آخر فاتورة مقفولة للعربية بيوم.
  • بيروح للمالك الحالي للعربية.
  • بيتبعت مرة واحدة بس لكل فاتورة.
  • يعني الكاشير لازم يدخّل "معاد الصيانة الجاية" في الفاتورة، وإلا مفيش تذكير.

تذكير المديونية

  • بيتبعت لما يعدّي debt_reminder_days يوم من غير أي حركة: لا فاتورة جديدة عليها فلوس، ولا دفعة (حتى لو جزئية)، ولا تذكير سابق.
  • بيتكرر كل نفس الفترة لحد ما يسدد كله.
  • المبلغ في الرسالة هو إجمالي مديونية العميل على كل عربياته، محسوب وقت الإرسال.

نص hint مقترح:

• تذكير الصيانة: "هيتبعت للعميل رسالة واتساب قبل معاد الصيانة اللي في الفاتورة بيوم."

• تذكير المديونية: "هيتبعت للعميل اللي عليه فلوس رسالة كل X يوم لحد ما يسدد. أي دفعة أو فاتورة جديدة بتبدأ العد من الأول."

شكل الرسايل اللي بتوصل للعميل

تذكير من مركز ابناء السنبلاوين 🔧
معاد صيانة عربيتك (ب ج 456) بكرة 2026-11-04.
مستنيينك!
للتواصل: 01xxxxxxxxx
تذكير من مركز ابناء السنبلاوين
إجمالي المديونية المستحقة عليك: 1,250.00 جنيه.
برجاء السداد في أقرب وقت.

سطر "للتواصل" بيظهر بس لو المركز مسجّل رقم تليفون في الإعدادات (phone).

  "recipient": "201001234567",
  "order": null,
  "receipt": null,
  "customer": { "id": 9, "name": "أحمد علي" },   // new

  "sent_at": 1793174400,
  "created_at": 1793174395
}
